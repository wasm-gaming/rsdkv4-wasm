## Summary
Implement a global drag-and-drop overlay when dragging files over the application page, and update `.slot-card[in-memory]` elements in `GameLauncher.html` to display detailed save game information (character, zone, lives, score, emeralds) for non-empty save slots, while maintaining new game creation functionality for empty slots.

## Planned Changes

### 1. Global Drag & Drop Overlay (`src/craft/components/DropForm.html` & `src/craft/App.html`)
- Modify `DropForm.html` to handle window-level `dragenter`, `dragover`, `dragleave`, and `drop` events using a depth counter to track drag state accurately without flickering.
- Transform `DropForm.html` into a fixed, full-screen glassmorphism overlay (`position: fixed; inset: 0; z-index: 1000`) that only displays when `isDragOver` is `true`.
- Embed `<DropForm @files="onFiles" />` in `App.html` so users can drag `Data.rsdk` or save files anywhere on the page to import them.

### 2. Save Game Slot Information (`src/craft/views/GameLauncher.html` & `src/craft/services/game.service.js`)
- Update `GameLauncher.html` to check `gameService.selectedGame.savegame[i]` for each slot `i` (0 to 3):
  - **Saved Slot (`!slotData.empty`)**:
    - Display character portrait corresponding to `slotData.character` (Sonic, Tails, Knuckles, Sonic & Tails).
    - Display zone/stage name (`ZONE 1`, `SPECIAL STAGE`, etc.).
    - Display stats: Lives, Emeralds, Score.
    - Render "PLAY" / "CONTINUE" button to launch the game using `slot: i` and `player: slotData.character`.
  - **Empty Slot (`slotData.empty` / no save data)**:
    - Display "NEW GAME" badge / title.
    - Provide interactive character selection (cycling Sonic, Tails, Knuckles, Sonic & Tails).
    - Render "START" / "PLAY" button to initialize a new game in slot `i`.
